# じぶんの宝石 — 配信

iOS アプリ「じぶんの宝石」が読む、**公開データだけ**の置き場です。

| ファイル | 中身 | 出どころ |
|---|---|---|
| `prices.json` | 地金の相場（円/グラム） | 田中貴金属工業の公表値 |
| `weather.json` | 今日と明日の天気（全国56予報区） | 気象庁（出典：気象庁ホームページ） |

**利用者の情報は1バイトも入っていません。**アプリはこの2本を読むだけで、
**何も送りません**（送信の口が1か所もないことを実測で確かめています）。

気象庁のデータは「公共データ利用規約（第1.0版）」に従って加工・再配布しています。
